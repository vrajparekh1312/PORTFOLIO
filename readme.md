## 📖 About The Project

This is a modern developer portfolio built using **HTML, CSS, JavaScript, and Three.js**.

It is designed to provide a **unique and immersive user experience** through:

* Smooth animations
* Interactive UI elements
* 3D visual effects
* AI assistant integration

🎯 The goal of this project is to showcase my **technical skills, creativity, and frontend expertise**.
